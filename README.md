# 🚚 SupplyPilot-AI

An AI-powered Closed-Loop Prescriptive Analytics System for Supply Chain Management.

---

## 📖 Project Overview

SupplyPilot-AI is an intelligent decision support system designed to help supply chain managers predict shipment delays, generate optimized recommendations, execute operational decisions, and continuously improve through closed-loop learning.

Unlike traditional dashboards that only display predictions, SupplyPilot-AI recommends the best course of action and learns from real-world outcomes.

---

## ✨ Features

- 📈 Predict shipment delays using XGBoost
- ⚙️ Generate optimized recommendations with SciPy/PuLP
- 🔄 Execute decisions through FastAPI APIs
- 🗄️ Store decisions in PostgreSQL
- 📊 Decision ROI Analytics
- 🤖 Continuous Model Retraining
- 📉 Interactive Dashboard built with React
